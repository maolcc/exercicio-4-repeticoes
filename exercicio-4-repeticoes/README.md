# Exercício 4 — Estrutura de Repetições (complementar)

**Disciplina:** Lógica de Programação e Algoritmos

## Objetivo

Praticar estruturas de repetição (`para`, `enquanto` e `repita`) junto com contadores, acumuladores, validação de dados e estruturas condicionais.

## Como executar

Os algoritmos seguem a sintaxe do VisuAlg. Para executar, copie o bloco de pseudocódigo de um exercício, cole no VisuAlg e pressione F9.
